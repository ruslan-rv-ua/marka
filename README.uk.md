## Про програму

**Marka** — це портативна програма для перегляду Markdown-файлів на Windows, створена на базі [Tauri](https://tauri.app/) з **доступністю в основі**. Вона забезпечує повну підтримку екранних читачів (NVDA) та навігацію через клавіатуру.

- **Без інсталятора** — один портативний `.exe` файл
- **Доступність в основі** — оптимізовано для екранного читача NVDA
- **Авто-локалізація** — визначає мову Windows (англійська / українська)
- **Легка** — мінімум залежностей, швидкий запуск

## Можливості

- 📖 **Рендеринг Markdown** — заголовки, таблиці, списки, цитати
- 💻 **Блоки коду** — підсвітлення синтаксису через [highlight.js](https://highlightjs.org/) з кнопками копіювання
- 🖼️ **Вбудовані медіа** — зображення, відео, аудіо з локальних шляхів
- 🔗 **Навігація** — посилання на `.md` файли відкриваються в програмі; зовнішні URL відкриваються в браузері
- 🎨 **Перемикання теми** — темна/світла тема (Ctrl+T), параметри зберігаються
- 🔤 **Розмір шрифту** — регульований 10–72px (Ctrl+= / Ctrl+-)
- 📏 **Управління відступом** — регулювання горизонтального відступу (Ctrl+[ / Ctrl+])
- ⚙️ **Збереження налаштувань** — зберігаються поруч з програмою
- 📌 **Асоціація файлів** — файли `.md` автоматично відкриваються в Marka
- 💬 **Підтримка CLI** — `marka.exe шлях\до\файла.md`

## Доступність

Marka розроблена для користувачів екранних читачів з першокласною підтримкою NVDA:

- **Структура документа** — вміст позначений як `role="document"` і можна керуватися клавіатурою з правильним управлінням фокусом
- **Ориєнтири блоків коду** — кожен блок `<pre>` є доступною через клавіатуру областю з описовими ARIA-етикетками
- **Живі анонси** — дії копіювання, зміни теми та помилки анонсуються через регіони `aria-live`
- **Обробка помилок** — помилки позначені `role="alert"` для негайного анонсу
- **Навігація клавіатурою** — усі функції доступні через клавіатуру; комбінації клавіш використовують коди, незалежні від розкладки (працює з будь-якою розкладкою)
- **Локалізація** — весь текст інтерфейсу українською або англійською мовою залежно від мови системи Windows
- **Відновлення фокусу** — автоматичне відновлення фокусу на вмісті після завантаження файлу, що викликає оновлення віртуального буфера NVDA

Див. розділ **Комбінації клавіш** нижче для повного списку.

## Інсталяція

### Варіант 1: Портативна версія (Рекомендується)

1. Перейдіть на [Releases](https://github.com/ruslan-rv-ua/marka/releases)
2. Завантажте `marka-{version}-windows-x64.zip`
3. Розпакуйте ZIP-файл
4. Запустіть `marka.exe`

### Системні вимоги

- **ОС:** Windows 10 (версія 1803+) або Windows 11
- **Microsoft WebView2 Runtime**
  - Вбудований в Windows 10 (21H2+) та всі версії Windows 11
  - Якщо у вас старіша версія Windows 10, завантажте з [Microsoft Edge WebView2](https://developer.microsoft.com/en-us/microsoft-edge/webview2/)

- **Visual C++ Redistributable (2022)**
  - Зазвичай вже встановлено на більшості систем
  - Якщо Marka не запускається, завантажте з [Microsoft](https://aka.ms/vs/17/release/vc_redist.x64.exe)

### Варіант 2: Scoop

Якщо ви використовуєте [Scoop](https://scoop.sh/):

```powershell
scoop bucket add ruslan-rv-ua https://github.com/ruslan-rv-ua/scoop-bucket
scoop install marka
```

Цей метод автоматично керує оновленнями й збереже ваші налаштування.

## Використання

### Відкриття файлів

- **Діалог вибору:** Натисніть **Ctrl+O**, щоб переглянути файл `.md`
- **CLI:** `marka.exe C:\шлях\до\файла.md`
- **Асоціація файлів:** Двічі клацніть на будь-якому файлі `.md` (автоматично зареєстровано)

### Комбінації клавіш

| Комбінація | Дія |
|----------|-----|
| **Ctrl+O** | Відкрити діалог вибору файла |
| **Ctrl+=** або **Ctrl+NumpadAdd** | Збільшити розмір шрифту (+1px, макс 72px) |
| **Ctrl+-** або **Ctrl+NumpadSubtract** | Зменшити розмір шрифту (-1px, мін 10px) |
| **Ctrl+[** | Зменшити горизонтальний відступ (-5%, мін 0%) |
| **Ctrl+]** | Збільшити горизонтальний відступ (+5%, макс 25%) |
| **Ctrl+T** | Перемикати темну/світлу тему |
| **Escape** | Закрити вікно |
| **Tab** | Перейти на кнопки копіювання в блоках коду та ориєнтирах |

**Примітка:** Усі комбінації клавіш використовують коди, незалежні від розкладки, і працюють з будь-якою розкладкою клавіатури (QWERTY, AZERTY, кирилиця тощо).

## Побудова з вихідного коду

### Передумови

- [Rust](https://www.rust-lang.org/) (остання стабільна версія)
- [Node.js](https://nodejs.org/) 20+
- [pnpm](https://pnpm.io/) 10+
- [just](https://github.com/casey/just) (runner завдань)

### Розробка

**З just (task runner):**

```bash
pnpm install
just dev           # Tauri dev-сервер (Vite + Rust watcher)
just vite-dev      # Тільки frontend (Vite на порті 1420)
just clean         # Очистити артефакти Rust
```

**Без just:**

```bash
pnpm install
pnpm vite:dev &    # Запустити Vite dev-сервер у фоні
cargo tauri dev    # Запустити Tauri dev-сервер
```

### Побудова для продакшену

**З just:**

```bash
just build         # Оптимізована побудова (повільніше, мінімальний exe)
just build-fast    # Швидка побудова (швидша компіляція, більший exe)
```

**Без just:**

```bash
pnpm vite:build
cargo tauri build --release
```

Побудовані виконавчі файли знаходяться в `src-tauri/target/release/`.
