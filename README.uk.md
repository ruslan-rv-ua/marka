## Про програму

**Marka** — це портативний інструмент для перегляду Markdown-файлів у Windows, розроблений на базі [Tauri](https://tauri.app/) з **акцентом на доступність**. Програма забезпечує повноцінну підтримку екранних читачів (зокрема NVDA) та зручну навігацію з клавіатури.

- **Портативність** — один `.exe` файл, що не потребує встановлення
- **Доступність понад усе** — оптимізовано для роботи з NVDA
- **Автоматична локалізація** — інтерфейс адаптується до мови Windows (UA/EN)
- **Легкість і швидкість** — мінімальні системні вимоги та миттєвий запуск

## Можливості

- 📖 **Якісний рендеринг** — підтримка заголовків, таблиць, списків та цитат
- 💻 **Робота з кодом** — підсвічування синтаксису ([highlight.js](https://highlightjs.org/)) та швидке копіювання
- 🖼️ **Локальні медіа** — відображення зображень, відтворення відео та аудіо за локальними шляхами
- 🔗 **Зручна навігація** — посилання на `.md` відкриваються в програмі, зовнішні URL — у браузері
- 🎨 **Зміна тем** — миттєве перемикання між темною та світлою темами (Ctrl+T)
- 🔤 **Налаштування шрифту** — зміна розміру тексту від 10 до 72 пікселів (Ctrl+= / Ctrl+-)
- 📏 **Керування відступами** — регулювання бічних полів для комфортного читання (Ctrl+[ / Ctrl+])
- ⚙️ **Автозбереження** — ваші налаштування автоматично зберігаються поруч із програмою
- 📌 **Асоціація файлів** — автоматичне відкриття `.md` файлів через Marka
- 💬 **Підтримка CLI** — можливість запуску через термінал: `marka.exe шлях\до\файла.md`

## Доступність

Marka розроблена з урахуванням потреб користувачів екранних читачів та має нативну підтримку NVDA:

- **Логічна структура** — основний вміст позначений як `role="document"` для коректної навігації
- **Орієнтири в коді** — кожен блок `<pre>` є окремим регіоном із описовою ARIA-міткою
- **Динамічні сповіщення** — копіювання, зміна теми чи помилки озвучуються через `aria-live`
- **Обробка помилок** — критичні повідомлення мають статус `role="alert"` для негайного озвучення
- **Клавіатурний доступ** — усі функції доступні через гарячі клавіші, що працюють незалежно від розкладки
- **Локалізація** — мова інтерфейсу відповідає системним налаштуванням Windows
- **Керування фокусом** — автоматичне повернення фокусу до тексту після відкриття файлу для оновлення буфера NVDA

Повний перелік гарячих клавіш наведено в розділі **Комбінації клавіш**.

## Інсталяція

### Варіант 1: Портативна версія (Рекомендується)

1. Перейдіть на [Releases](https://github.com/ruslan-rv-ua/marka/releases)
2. Завантажте `marka-{version}-windows-x64.zip`
3. Розпакуйте ZIP-файл
4. Запустіть `marka.exe`

### Системні вимоги

- **ОС:** Windows 10 (версія 1803+) або Windows 11
- **Microsoft WebView2 Runtime**
  - Вбудований в Windows 10 (21H2+) та всі версії Windows 11
  - Якщо у вас старіша версія Windows 10, завантажте з [Microsoft Edge WebView2](https://developer.microsoft.com/en-us/microsoft-edge/webview2/)

- **Visual C++ Redistributable (2022)**
  - Зазвичай вже встановлено на більшості систем
  - Якщо Marka не запускається, завантажте з [Microsoft](https://aka.ms/vs/17/release/vc_redist.x64.exe)

### Варіант 2: Scoop

Якщо ви використовуєте [Scoop](https://scoop.sh/):

```powershell
scoop bucket add ruslan-rv-ua https://github.com/ruslan-rv-ua/scoop-bucket
scoop install marka
```

Цей метод автоматично керує оновленнями й збереже ваші налаштування.

## Використання

### Відкриття файлів

- **Діалог вибору:** Натисніть **Ctrl+O**, щоб переглянути файл `.md`
- **CLI:** `marka.exe C:\шлях\до\файла.md`
- **Асоціація файлів:** Двічі клацніть на будь-якому файлі `.md` (автоматично зареєстровано)

### Комбінації клавіш

| Комбінація | Дія |
|----------|-----|
| **Ctrl+O** | Відкрити діалог вибору файла |
| **Ctrl+=** або **Ctrl+NumpadAdd** | Збільшити розмір шрифту (+1px, макс 72px) |
| **Ctrl+-** або **Ctrl+NumpadSubtract** | Зменшити розмір шрифту (-1px, мін 10px) |
| **Ctrl+[** | Зменшити горизонтальний відступ (-5%, мін 0%) |
| **Ctrl+]** | Збільшити горизонтальний відступ (+5%, макс 25%) |
| **Ctrl+T** | Перемикати темну/світлу тему |
| **Escape** | Закрити вікно |


**Примітка:** Усі комбінації клавіш використовують коди, незалежні від розкладки, і працюють з будь-якою розкладкою клавіатури (QWERTY, AZERTY, кирилиця тощо).

## Побудова з вихідного коду

### Передумови

- [Rust](https://www.rust-lang.org/) (остання стабільна версія)
- [Node.js](https://nodejs.org/) 20+
- [pnpm](https://pnpm.io/) 10+
- [just](https://github.com/casey/just) (runner завдань)

### Розробка

**З just (task runner):**

```bash
pnpm install
just dev           # Tauri dev-сервер (Vite + Rust watcher)
just vite-dev      # Тільки frontend (Vite на порті 1420)
just clean         # Очистити артефакти Rust
```

**Без just:**

```bash
pnpm install
pnpm vite:dev &    # Запустити Vite dev-сервер у фоні
cargo tauri dev    # Запустити Tauri dev-сервер
```

### Створення релізної версії

**Через `just`:**

```bash
just build         # Оптимізована збірка (мінімальний розмір файлу)
just build-fast    # Швидка збірка для тестування
```

**Без використання `just`:**

```bash
pnpm vite:build
cargo tauri build --release
```

Готові виконавчі файли будуть знаходитися в директорії `src-tauri/target/release/`.
