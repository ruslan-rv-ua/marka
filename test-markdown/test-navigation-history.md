# Тестування історії навігації

Цей файл допоможе перевірити, чи коректно працює історія відкритих файлів у застосунку, і як вона взаємодіє з навігацією вперед/назад через клавіатуру.

## Кроки для перевірки

Щоб перевірити весь стек історії, виконайте наступну послідовність дій:

### 1. Відкриття файлів (заповнення історії)
1. Відкрийте цей файл: `test-navigation-history.md` (ви вже тут).
2. Натисніть на це посилання, що веде до іншого файлу: [Перейти до test-links.md](test-links.md). (Або відкрийте його через `Ctrl+O`).
3. З файлу `test-links.md` відкрийте через `Ctrl+O` третій файл, наприклад `test-complete.md`.

*Ваша історія тепер: `test-navigation-history.md` -> `test-links.md` -> `test-complete.md`.*

### 2. Навігація "Назад" (Alt + Стілька Ліворуч)
1. Натисніть `Alt+Left`. Ви маєте повернутися до `test-links.md`.
2. Натисніть `Alt+Left` ще раз. Ви маєте повернутися сюди, до `test-navigation-history.md`.
3. Натисніть `Alt+Left` втретє. Повинен пролунати звуковий сигнал `aria-live` (повідомлення у Screen Reader: "Немає попередніх переглядів" / "No previous history"). Файл не має змінитись.

### 3. Навігація "Вперед" (Alt + Стрілка Праворуч)
1. Натисніть `Alt+Right`. Ви маєте перейти назад до `test-links.md`.
2. Натисніть `Alt+Right` ще раз. Ви маєте перейти до `test-complete.md`.
3. Натисніть `Alt+Right` втретє. Перехід не відбудеться, ви почуєте попередження: "Немає наступних переглядів" / "No next history".

### 4. Відгалуження історії
1. Поверніться до `test-links.md` (через `Alt+Left`).
2. Тепер натисніть на інше посилання, оберіть або відкрийте через `Ctrl+O` новий файл (наприклад, [test-images.md](test-images.md)).
3. Спробуйте натиснути `Alt+Right` ("Вперед").
*Очікувана поведінка:* перехід вперед має бути недоступним ("No next history"), оскільки історія "вперед" (файл `test-complete.md`) видаляється при переході за новим посиланням після кроку назад, як це працює в стандартних веб-браузерах.

### 5. Інтеграція зі Screen Reader
Під час виконання цих кроків із запущеним NVDA, програма має щоразу оголошувати назву відкритого файлу: *"Відкрито: test-links.md"*.
