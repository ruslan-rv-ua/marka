# Зміна масштабу та відступів

Цей файл призначений для ручного тестування клавіатурних скорочень зміни розміру шрифту та горизонтальних відступів.

## Інструкція з тестування

### 1. Зміна розміру шрифту

1. **Збільшення:** натискайте `Ctrl+=` (або `Ctrl+Num+`). Текст має збільшуватися (максимум до 72px).
2. **Зменшення:** натискайте `Ctrl+-` (або `Ctrl+Num-`). Текст має зменшуватися (мінімум до 10px).
3. **Перевірка лімітів:** дійдіть до мінімального та максимального значення, щоб переконатися, що програма не дозволяє вийти за їх межі.
4. **Міжсесійне збереження:** змініть масштаб, закрийте програму і відкрийте цей файл знову. Зміни мають зберегтися.

### 2. Зміна горизонтальних відступів

1. **Збільшення відступів:** натискайте `Ctrl+]`. Поля з обох боків мають збільшуватись (максимум до 25%).
2. **Зменшення відступів:** натискайте `Ctrl+[`. Поля мають зменшуватись (мінімум до 0% — текст стає на всю ширину).
3. **Міжсесійне збереження:** налаштуйте комфортний відступ, перезапустіть застосунок і переконайтеся у його збереженні.

### 3. Скидання до налаштувань за замовчуванням

Ця комбінація (`Ctrl+0`) є новою фічею. Вона має відновити стандартні значення (16px для шрифту та 10% для відступів).

1. Спочатку встановіть дуже великий масштаб шрифту (`Ctrl+=` багато разів).
2. Далі зробіть максимально широкі відступи (`Ctrl+]` до упору).
3. Тепер натисніть `Ctrl+0`.
4. **Результат:** шрифт повинен повернутися до нормального розміру (16px), а відступи — до стандартних 10%.
5. Перезавантажте `Marka`. Стандартні налаштування мають бути збережені.

---

*Примітка.* Щоб перевірити справжні значення, можна відкрити DevTools (через `правоклік` -> `Оглянути` в debug режимі) і переглянути CSS змінні `--font-size` та `--padding-x` на тегу `<html>`.
