# Дизайн: Генерація набору іконок з logo.svg

**Дата:** 2026-03-21
**Тема:** Створення системи іконок для Tauri додатку Marka з SVG логотипу
**Статус:** Затверджено

## Мета

Замінити стандартні Tauri іконки на кастомні, видобуті з існуючого `logo.svg`, та підготувати зображення для документації (README). Іконки повинні мати прозорий фон та бути інтегровані в збірку так, щоб з'являтися в exe-файлі та на панелі завдань Windows.

## Контекст

- **Поточний стан:** проект має `logo.svg` (512×512, чорний фон з білим borderm, буква "M")
- **Tauri конфіг:** вже налаштований на bundled іконки (`tauri.conf.json`, рядки 39-43)
- **Папка іконок:** `src-tauri/icons/` містить placeholder іконки за замовчуванням
- **Цільова платформа:** Windows (NSIS/MSI установники, exe)

## Вихідні артефакти

### 1. Іконки для Tauri bundle (`src-tauri/icons/`)

| Файл | Розмір | Назначение | Формат |
|------|--------|------------|--------|
| `32x32.png` | 32×32 px | Меню, малі іконки | PNG (RGBA) |
| `64x64.png` | 64×64 px | Проміжний розмір | PNG (RGBA) |
| `128x128.png` | 128×128 px | Основна іконка додатку | PNG (RGBA) |
| `128x128@2x.png` | 256×256 px | Retina/висока щільність | PNG (RGBA) |
| `icon.ico` | Multi-res | Windows exe/установник | ICO (містить 32, 64, 128 px) |

### 2. Зображення для документації (`assets/`)

| Файл | Розмір | Назначение |
|------|--------|------------|
| `logo-256x256.png` | 256×256 px | README (компактна) |
| `logo-512x512.png` | 512×512 px | README (повнорозмірна) |

**Формат:** PNG з прозорим фоном (RGBA)

## Технічна реалізація

### Конвертування SVG → PNG

**Інструмент:** ImageMagick (`magick` або `convert`)

**Процес:**
1. Видалити чорний фон і білий border из logo.svg
2. Залишити тільки букву "M" на прозорості
3. Експортувати в PNG у потрібних розмірах

**Команди (приблизно):**
```bash
# Приклад: масштабування SVG в PNG
magick convert logo.svg -trim -background none -resize 32x32 src-tauri/icons/32x32.png
magick convert logo.svg -trim -background none -resize 128x128 src-tauri/icons/128x128.png
magick convert logo.svg -trim -background none -resize 256x256 src-tauri/icons/128x128@2x.png
```

### Генерація ICO-файлу

**Інструмент:** ImageMagick `convert`

**Процес:**
- Об'єднати кілька PNG у одну ICO (один файл з кількома розмірами)

**Команда (приблизно):**
```bash
magick convert 32x32.png 64x64.png 128x128.png -colors 256 src-tauri/icons/icon.ico
```

### Інтеграція з Tauri

**Файл:** `src-tauri/tauri.conf.json` (рядки 39-43)

```json
"bundle": {
  "icon": [
    "icons/32x32.png",
    "icons/128x128.png",
    "icons/icon.ico"
  ]
}
```

✅ Конфіг уже вказує на ці файли. Новим файлам просто замінять старі.

**При білді** (`pnpm build`):
- Tauri читає конфіг
- Інклюджує іконки в exe для Windows
- Крім того, NSIS/MSI установник використовуватимуть icon.ico

**Результат на користувача:**
- Іконка в заголовку вікна
- Іконка на панелі завдань Windows
- Іконка в установнику та на Desktop

## Можливі ризики & смягчення

| Ризик | Смягчение |
|-------|-----------|
| SVG містить складні елементи, які погано масштабуються | Спробувати кілька методів (resize, interpolation), обрати найкращий візуально |
| ICO вимагає точних розмірів | Использовать ImageMagick з явними параметрами, перевірити результат |
| Іконки не з'являються в exe | Перевірити, що tauri.conf.json вказує на правильні шляхи й формати |
